# 你好，1983 · 国庆特辑

一个**多网页、可滑动浏览**的国庆祝福站点，**只以两位主角的视角**展开：
**夏晓兰**（破局者 · 秒针）与**周诚**（守护者 · 钟摆）。

选这两个人，是因为在《你好，1983》里**正是夏晓兰手里那块钟表跌落、指针回转**，
才把她送回 1983 年 —— 「钟」不是装饰，是这部剧的开关。而周诚的时间是另一种走法：
她不抢他就不稳，他不守她就跑不远。同一段 1983，两个人各自有一块表。

---

## 快速开始

直接双击 `index.html` 即可（纯静态、零依赖、离线可用）。

```powershell
python -m http.server 8080
# 然后访问 http://localhost:8080/index.html
```

| 序 | 文件 | 内容 | 钟的意象 |
|---|---|---|---|
| 1 | `index.html` | 封面：进入时指针先倒转 1900ms 再走正；引言讲述钟表跌落的那一夜；两位主角入口 | 表盘 / 指针倒转 |
| 2 | `xiaxiaolan.html` | **夏晓兰 · 破局者**（周也 饰），六节 | 秒针 |
| 3 | `zhoucheng.html` | **周诚 · 守护者**（翟潇闻 饰），六节 | 钟摆 |
| 4 | `two-views.html` | **双视角对读**：快与慢 / 进与守 / 一个人的倔强，两个人的底气 | 两块表 |
| 5 | `blessing.html` | 两条祝福并陈 → 共祝祖国（灯笼 + 烟花）→ 尾声：定格在 `10:01` 的钟 | 报时 |

### 两位主角的六节结构

每个人物页都用同一条纵深线展开，一共六节：

1. **人物卡** —— 姓名、定位、饰演者、题词、小传、关键词标签
2. **他 / 她是谁** —— 三个身份（她：现代女高管 / 十八岁的农村姑娘 / 自己人生的老板；他：桀骜的少年 / 沉默的行动派 / 清醒的同行者）
3. **他 / 她怎么走** —— 她走过四步：站稳 · 读书 · 做买卖 · 立住；他的三条分寸：不拦 · 不问值不值得 · 把后路铺好
4. **钟语** —— 一枚会走时的真表盘 + 一句比喻（秒针 / 钟摆）
5. **剧中的三句话** —— 取自该剧公开流传的金句合集
6. **国庆祝福** —— 以这个人的视角，为建国 77 周年送上一段话

### 双视角对读页

同一段 1983，两种读法并排陈列：

| | 夏晓兰 | 周诚 |
|---|---|---|
| 其一 | 快 —— 永远比时代早走半格 | 慢 —— 每一摆都摆匀，快了会摔 |
| 其二 | 进 —— 要的是"往前一步" | 守 —— 要的是"后路不断" |
| 其三 | 她的倔强，脚下垫着别人的功夫 | 他不出面，只想让她回头时一定有人在 |

## 操作方式

| 操作 | 效果 |
|---|---|
| 上下滑动 / 滚动滚轮 | 在当前页内切换分节 |
| 滚轮滑到页尾后继续下滑 | 翻到下一张网页 |

## 设计说明

- **钟元素**贯穿全站：角标齿轮、每章一枚 SVG 表盘、双视角页两块并置的表、翻页钟声、结尾定格在 `10:01`（十月一日）的钟。
- **配色**：深绛红夜底 + 鎏金文字 + 老纸张卡片（引言章节），点缀国旗红。
- **两套色相区分两个视角**：她的一侧偏金，他的一侧偏靛青，在双视角页一眼可辨。
- **无外部依赖**：不含 CDN、图片或字体文件；表盘、齿轮、灯笼、五星全部为手写 SVG。

### 主角剧照位（已装入）

每个人物页第一节「主角视角 01 / 02」都有一张剧照框：

| 文件 | 出现位置 | 尺寸 |
|---|---|---|
| `assets/gifs/xiaxiaolan.gif` | 夏晓兰 · 主角视角 01 | 602×451 |
| `assets/gifs/zhoucheng.png` | 周诚 · 主角视角 02 | 640×640（人脸密集区方裁） |

来源是公开图片索引里按「剧名 + 角色名 + 演员名」检索到的剧照缓存图，
且只保留来源页标题明确写了对应角色 / 演员的那些。
**生成环境看不到图像内容** —— 只能程序化确认是「人脸密集的照片」并按肤色密度自动方裁，
无法确认画面里的人是谁（第一版就因此装错了周诚，已更换）。

**换图入口：[pick-image.html](pick-image.html)** —— 双击打开，20 张候选（每位 10 张）
平铺对比，带来源标题与近景度，挑好复制卡片下的命令即可。
加载顺序为 `gif → png → jpg → jpeg → webp`：**任意格式都能用**，
放一个 `xiaxiaolan.gif` 进去会自动顶掉现有的 png。详见
[assets/gifs/README.md](assets/gifs/README.md)。

因为公开渠道只取到**单帧图**（索引把动图压平了），页面用 CSS 给静态剧照加了
**缓慢推近 + 扫光**，所以看起来是动的；换成真正的 GIF 后这层动效依然成立。
目录为空时会回落到原创 SVG 动画占位（她 = 秒针，他 = 钟摆），不会破图。

  因此页面只标注"《你好，1983》台词"，未逐句署名说话人。「钟语」「祝福」为创作文案。
- 页面内置的两张主角剧照来自公开图片索引的缓存图，仅供个人观赏使用；
  如需公开发布，请自行确认版权或替换为自有素材。
- 全站不含任何剧照或受版权保护的素材，仅作国庆主题创作使用。

## 自检

`.qa/` 里的脚本用 Playwright（走本机 Edge）做回归，不是站点运行所需：

```powershell
node .qa/probe.cjs    # 18 项交互测试
node .qa/shots.cjs    # 1440×900 / 390×844 逐屏截图与越界检查
node .qa/overlap.cjs  # 滚动到底时是否被顶栏/底栏永久遮住
python .qa/pixels.py  # 截图像素体检

# 动图位链路验证（会临时生成再删除测试用 GIF）
python .qa/make_fixture_gif.py && node .qa/gifcheck.cjs
Remove-Item assets/gifs/xiaxiaolan.gif, assets/gifs/zhoucheng.gif -ErrorAction SilentlyContinue
```

最近一次结果：

- 交互回归 **18/18 通过**（含双视角页两个表盘、主角剧照位、触摸左右滑、键盘、报时开关、无 JS 报错）
- 剧照链路 **3/3 通过**：`xiaxiaolan.gif` 与 `zhoucheng.png` 都正确加载并隐藏占位动画，
  `pick-image.html` 的 20 张候选全部加载成功
- 剧照渲染确认 **2/2**：两张图确实画在「主角视角 01 / 02」框内（框内肤色占比 30.8% / 34.1%）
- 桌面端（1440×900）**22 个分节全部正好铺满一屏**（fill 1.00）
- 遮挡检查 **10/10 无遮挡**（滚动到底也不会被顶栏/底栏永久挡住）
- 手机端文字最密的几节（引言、人物小传、行走刻度）高于一屏，属正常阅读滚动
