## 想换图？先看 `pick-image.html`

项目根目录下有 **`pick-image.html`** —— 双击打开，里面把两位主角各 10 张候选
（共 20 张）平铺出来，标注了来源标题和「近景度」。挑好后把卡片下面的命令
复制到 PowerShell 执行即可，或者直接告诉我编号。

```powershell
Copy-Item assets/gifs/candidates/zhoucheng-10.png assets/gifs/zhoucheng.png -Force
```

## 来源说明（请务必看一眼）

这些图是在公开图片索引里，用「剧名 + 角色名 + 演员名」检索到的剧照缓存图，
并且**只保留来源页标题里明确写了对应角色 / 演员的那些**。

**生成环境看不到图像内容**：我只能用程序确认它们是「人脸密集的横向/竖向照片」，
并按肤色密度自动选择了方裁范围，**无法确认画面里的人到底是谁**。
所以首次装上去的那张周诚图是错的 —— 已按来源标题换成
「【翟潇闻】武力值max的周诚」那张。请你再确认一眼。

## 换图规则

- 页面会自动按 `gif → png → jpg → jpeg → webp` 的顺序找同名文件，
  **任意格式都行**，先找到的先用。
- 所以：想用动图，就把 `xiaxiaolan.gif` 放进这个目录（gif 优先级最高，会自动顶掉 png）。
- 建议正方形或接近正方形（页面按 `object-fit: cover` 居中裁切），单文件 **2 MB 以内**。
- 没有任何文件时回落到原创 SVG 动画占位（她 = 秒针，他 = 钟摆），不会破图。
- 只会命中第一个存在的格式，因此排在后面的格式会有一次 `ERR_FILE_NOT_FOUND`
  控制台提示 —— 属可选素材的正常现象，不影响页面。
